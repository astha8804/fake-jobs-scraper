# Fake Python Jobs Scraper

A Python web scraper that collects job listings from
https://realpython.github.io/fake-jobs/ and saves them to a CSV file.

Project URL: PASTE_THE_COPIED_LINK_HERE

## Requirements
- Python 3.8+
- requests
- beautifulsoup4

## Setup
pip install requests beautifulsoup4

## Usage
python job_scraper.py

The results are saved to `jobs.csv` (title, company, location, URL).
